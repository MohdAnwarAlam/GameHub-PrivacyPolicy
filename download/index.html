How to install

  1. Tap Download and open the file when it finishes.
  2. If Android asks, allow "Install unknown apps" for your browser (Settings → Apps → your browser).
  3. Tap Install, then open Mini Games Hub.

This is a test build shared directly (not from Google Play), so Android shows a standard warning for apps installed this way. The app has no internet access and asks for no permissions. See the privacy policy.
